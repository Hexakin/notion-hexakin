    FAQ

    What does this do?

    It strips the 32-character Notion ID from each filename, rewrites links in .md and .html files, and packages a new ZIP named clean_notion_export.zip.

    Does the ZIP leave this browser?

    No. The file is read locally and handed to a worker on this page. Nothing is uploaded.

    What about a ZIP inside a ZIP?

    If the export contains exactly one nested ZIP, unwrap is automatic. There is no toggle.

    What if two pages clean to the same name?

    The second file gets a (2) suffix so nothing is overwritten.

    Do I need an email to download?

    No. Email is optional and only appears after a successful clean.
